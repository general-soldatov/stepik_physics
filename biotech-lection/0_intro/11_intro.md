# Правила на занятиях
- Есть вопрос – тянем руку.
- Есть ответ на вопрос преподавателя – тянем руку. С места не выкрикиваем.
- Шуметь не надо. Нужно внезапно поговорить с соседом – тянем руку и выходим в коридор.
- Телефон не использовать (кроме оговоренных случаев).
- Если нужно выйти по надобности, в т.ч. позвонить, послушать голосовое, ответить на сообщение, послушать музыку – тянем руку.
- Опоздавших не ждём (кроме форс-мажорных обстоятельств).
